# View navigation controls

DisplayPipeline.navigateView(mode, deltaX, deltaY) accepts rotate, pan or zoom and finite CSS-pixel deltas. It updates the existing camera and OrbitControls target without changing object selection, Gumball, mouse mappings or scene geometry. Rotate orbits about the current target with the camera up axis and polar limits. Pan translates camera and target together using screen-space axes and viewport height. Zoom changes perspective distance or orthographic zoom; negative vertical deltas zoom in. Camera updates invalidate progressive rendering and mark viewport interaction.

PandaUI Preview exposes three 44px buttons in the upper-right corner. Drag with mouse or touch (pointer capture continues outside the button); release/cancel/Escape ends the gesture. Click/tap selects a persistent highlighted navigation mode: two-finger trackpad scrolling over the canvas rotates, pans or zooms. Ctrl+wheel (trackpad pinch) always zooms. Click again, Escape or window blur clears the mode. Scrolling over panels keeps normal panel behavior. Focused buttons support arrows; the zoom button also supports +/-; Enter/Space toggles the selected mode. The toolbar does not switch the normal scene selection mode. English labels and native title hints describe each action.
